## 교열 체크리스트 (필수)

### Layer 1: 기술적 교열 (Proofreading)

#### 1-1. 한국어 맞춤법
```
☑️ 맞춤법 검사 (문법, 띄어쓰기, 조사)
☑️ 시제 일관성 (과거/현재/미래 섞이지 않음)
☑️ 존댓말/부정댓말 통일
☑️ 중복 표현 제거 (예: "필요하다는 필요가")
☑️ 한자/한글 혼용 확인 (일관성)
```

#### 1-2. AI/기술 용어 표준화

| 수정 전 | 수정 후 | 비고 |
|--------|--------|------|
| 인공 지능 | 인공지능 | 합성어 띄어쓰기 금지 |
| 머신 러닝 | 머신러닝 | |
| 에듀 테크 | 에듀테크 | |
| 딥 러닝 | 딥러닝 | |
| 제너레이티브 AI | 생성형 AI | 초회: 영문, 이후 한글 통일 |
| 챗 GPT | ChatGPT | 브랜드명 정확히 |
| 구글 | Google (첫 언급) → 구글 (이후) | |

#### 1-3. 수치 포맷 통일

```
☑️ 모든 숫자 = 아라비아 숫자 (한글숫자 X)
 ❌ "오만 명" → ✅ "50,000명"
 
☑️ 단위 표기 통일
 - 억: 100억 원 (띄어쓰기 O)
 - 백만: 5 million → 500만
 - 초 단위: 5초 (단위 붙임)
 
☑️ 백분율: 85% (% 기호 사용)
☑️ 소수점: 3.14 (마침표 사용, 쉼표 X)
```

#### 1-4. 문장 복잡도 검사

```
☑️ 평균 문장 길이 < 30자
 ❌ 너무 길면: 마침표로 나누기
 
☑️ 한 문장 = 한 개념
 ❌ "정부는 정책을 발표했고 전문가들은 반대했으며 언론은 주목했다"
 ✅ 3개 문장으로 분리
 
☑️ 대명사 사용 최소화
 ❌ "그는 그것을 그렇게 했다"
 ✅ 명확한 주어/목어 명시
 
☑️ 정의되지 않은 약자 없음
 ❌ "LMS를..." (정의 없음)
 ✅ "학습관리시스템(LMS)을..."
```

#### 1-5. 영어 잔여 문장 자동 필터링/삭제

번역 과정에서 남은 영어 잔여 문장을 자동 감지하여 정리한다.

```
☑️ 영어 3단어 이상 연속 감지
 → 고유명사/전문용어가 아닌 일반 영어 문장은 자동 삭제
 → 예: "This is a new approach" (삭제)
 → 예외: "ChatGPT", "OpenAI", "GPT-4" 등 고유명사는 유지

☑️ 번역 가능한 영문 → 한국어로 자동 번역 교체
 → 영어 문장이 번역 가능한 내용이면 한국어로 번역하여 대체
 → 예: "The government announced" → "정부가 발표했다"

☑️ 원문 인용이 필요한 경우
 → blockquote 내 번역문 아래 영문 원문 표기
 → 형식:
   > "한국어 번역문"
   > _"Original English text"_
```

### Layer 2: 스타일/톤 검사 (Style & Tone)

#### 2-1. 경향신문 톤 유지

AskedTech는 "경향신문 스타일"을 기준으로 함:

```
✅ 요구되는 톤:
 - 전문적이면서 접근 가능
 - 신중하지만 명확
 - 중립적이지만 관심 있음
 - 긴급/흥미 보도하지만 자극적이지 않음

❌ 피할 톤:
 - 너무 학술적 (논문 같음)
 - 너무 캐주얼 (블로그 같음)
 - 선동적 (클릭베이트)
 - 무미건조 (뉴스 통신사 같음)
```

#### 2-2. 도치/역순 문장 검사

```
❌ 역순 과다: "AI를, 교육에 도입하려는 정부의..."
✅ 정순: "정부가 교육에 AI를 도입하려는..."

☑️ 피동형 과다 제거
❌ "교실에서 활용되는 AI"
✅ "교실에서 AI를 활용"
```

#### 2-3. 강조 수단 검사

```
☑️ **굵은글씨** — 중요 단어만 (남용 금지)
☑️ 인용 blockquote — 직접 언급이 있을 때만
☑️ 리스트 — 3개 이상 항목일 때만
☑️ 단락 나누기 — 자연스러운 흐름 유지
```

#### 2-4. 헤드라인 품질 검증

헤드라인은 기사의 첫인상이며, 번역 잔여물과 형식적 오류가 가장 두드러지는 부분이다.

```
☑️ "AI 교육 관련 최신 동향:" 포함
 → 자동 삭제 후 한국어로 재작성
 → 예: "AI 교육 관련 최신 동향: 정부, 디지털 교과서 도입" 
      → "정부, 디지털 교과서 전면 도입...AI 교육 체계화"

☑️ 영문 5단어 이상 포함
 → 한국어로 재작성
 → 예: "OpenAI Launches New GPT-5 Model for Education"
      → "오픈AI, 교육용 GPT-5 모델 출시"

☑️ 30자 초과 헤드라인
 → 핵심만 남기고 축약
 → 예: "교육부가 발표한 2026년 AI 교육 전면 도입 방안에 대한 종합 분석" (31자)
      → "교육부, 2026년 AI 교육 전면 도입 방안 발표"

☑️ "| 출처명" 포함
 → 출처명 제거
 → 예: "정부, AI 정책 발표 | 연합뉴스"
      → "정부, AI 정책 발표"
```

### Layer 3: 명확성 검사 (Clarity)

#### 3-1. 문맥 명확성

```
☑️ 주어-술어 호응
 ❌ "학교의 AI 도입은 많은 과제가 있다" (주어와 술어 불일치)
 ✅ "학교의 AI 도입에는 많은 과제가 있다"

☑️ 지칭 명확성
 ❌ "정부와 학교가 논의했다. 그들은..."
 ✅ "정부와 학교가 논의했다. 정부는..."

☑️ 인과관계 명확
 ❌ "AI 도입되었다. 교사 교육도 중요하다"
 ✅ "AI 도입되었기 때문에 교사 교육이 중요해졌다"
```

#### 3-2. 정의되지 않은 개념

```
☑️ 첫 언급 시 정의
 ❌ "생성형 AI 활용..."
 ✅ "생성형 AI(ChatGPT 같은 대규모 언어모델)를..."

☑️ 외국어 용어
 ❌ "Generative AI"
 ✅ "생성형 AI" (또는 첫 언급: "생성형 AI(Generative AI)")
```

#### 3-3. 표현의 일관성

```
☑️ 정책명 일관성
 ❌ "AI 교과서", "AI 과목", "AI 교육과정" (혼용)
 ✅ "AI 기본교육과정" (정책명 정확히)

☑️ 기관명 일관성
 ❌ "교육청", "서울교육청", "서울시교육청" (혼용)
 ✅ 첫 언급: 전체명 → 이후: 약칭
```

#### 3-4. 형식적 구조 감지/수정

AI 번역/생성 기사에서 흔히 발견되는 기계적 구조를 감지하고 자연스러운 IT 기사 구조로 재구성한다.

```
☑️ 4단계 고정 구조 감지
 → "배경과 맥락 → 주요 내용 → 글로벌 비교 → 향후 전망" 패턴
 → 감지 시: 자연스러운 IT 기사 구조로 재작성 지시
 → 개선 방향:
   - 리드(도입) → 핵심 사실 → 세부 전개 → 전망/의미
   - 각 섹션이 자연스럽게 이어지도록 흐름 재구성
   - H2 제목도 기사 내용에 맞게 개별화

☑️ 형식적 3분할 감지
 → "정부 측은 ~", "교육계는 ~", "국제적 관점에서는 ~" 패턴
 → 감지 시: 문맥에 맞게 자연스럽게 재구성
 → 개선 방향:
   - 주체별 단락 분리 대신 사건 흐름 중심 서술
   - "정부는 ~라고 밝혔다. 반면 교육 현장에서는 ~라는 우려가 나온다." 
     → 자연스러운 인과/대조 구조로 통합
   - "국제적 관점에서는" → 구체적 국가/기관 사례로 대체
```

### Layer 4: 구조 최종 검증 (Final Structure Check)

#### 4-1. 필수 요소 확인

```
☑️ AI 공개 배지 (상단 pill): **없어야 함** (기사 하단만 가능)
 ❌ 있으면: 제거
 
☑️ AI 법적 고지 (하단): **반드시 있어야 함**
 - 기사 맨 끝, 참고자료 아래
 - 텍스트: "본 기사는 AI가 작성했습니다 (AI 기본법 제31조)"
 - 스타일: font-size:13px, color:#cbd5e1
 
☑️ 참고 자료 섹션: **반드시 있어야 함** (3개 이상 링크)
 - 위치: 기사 본문 끝, AI 각주 바로 위
 
☑️ 수치 카드: **없어야 함**
 ❌ `<div style="display:flex">` 형태의 숫자 박스 → 제거
```

#### 4-2. HTML 검증

```
☑️ <article> 태그 없음 (모두 <div> 사용)
☑️ kg-card 주석 올바른가?
 ✅ <!--kg-card-begin: html--> ... <!--kg-card-end: html-->
 
☑️ 리드 박스 스타일 확인
 - border-left:4px solid {color}
 - background:#f8f9ff
 - padding:16px 20px
 
☑️ 섹션 h2 스타일 확인
 - font-size:19px
 - border-bottom:1px solid #e2e8f0

☑️ ⭐ 본문 내용 길이 확인 (NEW 2026-03-06)
 - HTML 길이: 1500자 이상? (이하면 REJECT)
 - 본문 단어 수: 200단어 이상? (이하면 REJECT)
 - 실제 뉴스 본문: 500자 이상? (이하면 REVISE)
 
 명령어: jq '.draft.html | length' article.json
 
 조건: 1500자 AND 200단어 AND 500자 이상 → PASS
 하나라도 부족 → REJECT (발행 금지)
 
 목적: 2026-03-05 LG 기사처럼 쓰레기 내용(3000자 미만 요약)
 Ghost에 발행되는 것 방지
```

#### 4-3. 태그 완정도 검증

기사 메타데이터의 태그가 누락되지 않았는지 검증한다.

```
☑️ 국내/해외 태그 누락
 → 국내 기사: "국내" 태그 자동 추가
 → 해외 기사: "해외" 태그 자동 추가
 → 둘 다 없으면 기사 내용 기반 자동 판별 후 추가

☑️ 해외 기사인데 지역 태그 없음
 → 기사 내용/출처 기반 region 태그 자동 추가
 → 예: 미국 기사 → "미국", "북미"
 → 예: 유럽 기사 → "유럽", "EU"
 → 예: 중국 기사 → "중국", "아시아"
 → 예: 일본 기사 → "일본", "아시아"

☑️ 주제 태그 최소 조건
 → 최소 1개 주제 태그 (AI, 교육, 에듀테크 등)
 → 최소 1개 지역/범위 태그 (국내/해외)
 → 해외 기사: 최소 1개 region 태그
```

## 교열 가이드라인

### 수정 vs 반환 기준

**이대로 발행 가능** (교열만 하고 발행):
- 문법/띄어쓰기 오류
- 용어 표준화 오류
- 수치 포맷 오류
- 경미한 톤 조정
- 영어 잔여 문장 삭제/번역 교체
- 헤드라인 축약/재작성
- 태그 누락 자동 추가

**반환 필요** (06-desk-approved/로 다시):
- 구조적 결함 (리드 박스 없음 등)
- 심각한 명확성 문제 (문장 이해 불가)
- 참고자료 완전히 빠짐
- 팩트체크 보완 필요
- 형식적 구조 전면 재작성 필요 (4단계 고정 구조 + 3분할 동시 감지 시)

## 예제

### Before (교열 전)
```html
<p>최근 교육부가 2025년 부터 AI 교육을 시행하겠다고 발표 했으며, 이는 엄청나게 중요한 변화이다. 왜냐하면 생성형 AI 도입의 필요성이 있기 때문 이다.</p>
```

### After (교열 후)
```html
<p>교육부가 22일 2025년부터 전국 중고교에서 AI 과목을 필수로 지정하기로 발표했다. 한국이 AI 교육을 국가 전략으로 삼은 첫 공식 입장이며, 교육과정에서 AI의 위치를 확정한 것이다.</p>
```

**수정사항:**
- "부터" 띄어쓰기 수정
- "했으며"의 쓸데없는 문제 제거 및 문장 분리
- "엄청나게 중요한" → 더 정확한 표현으로
- "왜냐하면 ~ 때문 이다" 비어색한 표현 → 정보 기반 재작성

### 영어 잔여 필터링 예제

**Before:**
```html
<h2>AI 교육 관련 최신 동향: Government unveils new AI education policy</h2>
<p>교육부가 새로운 정책을 발표했다. The policy includes mandatory AI curriculum. 이는 중요한 변화다.</p>
```

**After:**
```html
<h2>교육부, AI 교육 정책 전면 발표</h2>
<p>교육부가 새로운 정책을 발표했다. 이 정책에는 필수 AI 교육과정이 포함돼 있다. 이는 중요한 변화다.</p>
```

**수정사항:**
- 헤드라인 "AI 교육 관련 최신 동향:" 삭제 후 재작성
- 헤드라인 영문 → 한국어 재작성
- 본문 영어 잔여 문장 "The policy includes..." → 한국어 번역 교체

### 형식적 구조 수정 예제

**Before (4단계 고정 구조 + 3분할):**
```
## 배경과 맥락
정부 측은 AI 교육을 국가 과제로 삼았다...
## 주요 내용
교육계는 현장 준비가 부족하다고 지적한다...
## 글로벌 비교
국제적 관점에서는 한국이 뒤처져 있다...
## 향후 전망
앞으로는 변화가 예상된다...
```

**After (자연스러운 IT 기사 구조):**
```
## 교육부, 내년부터 전국 초중고에 AI 필수 과목 신설
정부가 내년부터 전국 초·중·고에 AI 필수 과목을 신설한다고 22일 밝혔다...
## "현장 준비는 전무"...교사·장비 부족 우려
교육 현장에서는 우려의 목소리가 나온다. 서울시교육청 관계자는...
## 싱가포르·일본, 이미 2023년 도입...한국 '출발선' 뒤처져
싱가포르는 2023년부터 전국 초등학교에 AI 교육을 의무화했다...
```

**수정사항:**
- 4단계 고정 구조 → 기사 내용에 맞는 개별 H2 제목
- "정부 측은/교육계는/국제적 관점에서는" 3분할 → 자연스러운 인과/대조 흐름
- 구체적 국가 사례로 "국제적 관점" 추상성 해소
